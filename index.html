Algorithm Visualizer

A comprehensive exploration of core pathfinding strategies.

BFS (Breadth-First)

Explores equally in all directions. Guarantees the shortest path on unweighted grids but can be slow.

DFS (Depth-First)

Plunges as deep as possible before backtracking. Uses minimal memory but rarely finds shortest paths.

DLS (Depth-Limited)

A constrained Depth-First Search that stops exploring at a specific depth limit to prevent infinite loops.

UCS (Uniform Cost)

Accounts for variable node weights (like terrain). Guarantees the cheapest overall path.

Greedy Best-First

Uses a heuristic to guess the closest path. Extremely fast, but doesn't guarantee the optimal route.

A* Search

The gold standard. Combines actual cost and heuristic prediction to guarantee the optimal path efficiently.
